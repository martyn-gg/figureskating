## Learn to Skate USA — the floor below everything else, added 06/09/2026

The guide had no element below an edge: everything in it started from a curve already
established, and `notCovered` said so nine times over in the words *the step wide and the
push back*. **Learn to Skate USA is the anchor for the basics** — chosen over Skate UK
because BIS publishes its Fundamentals curriculum as a **paid booklet** in the merch shop
(*Skate UK Fundamental Skills Booklet*, Fundamental Certificates Phases 1–8) rather than
as a free PDF, while Learn to Skate USA's is public.

**Both copies of Basic 1–6 were read on 06/09/2026 and agree**, level by level and skill by
skill. Neither carries a revision date or version marking — the same problem the BIS Skills
documents have, and the same answer: tell the generations apart by **structure**, not by a
date. Basic Skills is currently **six levels**; learntoskateusa.com's own Basic Skills page
says "a six level progressive curriculum". An older Basic 1–8 structure is still all over
club websites and is **not** current — treat any eight-level Basic list as legacy, the same
way the NISA Field Moves manuals are.

**The URLs above are club copies on content-delivery hosts, not learntoskateusa.com.** The
official media path (`learntoskateusa.com/media/1159/curriculum_basicskills.pdf`) 404s, and
the detailed curriculum appears to sit behind the member portal. So these are held as
*corroborated secondary copies*, and that is a weaker provenance than the BIS Skills PDFs.
Worth one attempt at the member portal before the basics pages come off `verified: false`.

**The organisation is Learn to Skate USA, which is U.S. Figure Skating's learn-to-skate
programme**, so these tests carry `governingBody: USFS` while their `name` stays *Learn to
Skate USA Basic N*. Do not silently call them *moves in the field* or *skills* — see the
vocabulary note below, which this is a third instance of.

## Cross-checked against, but not sourced from

Neither is the anchor; both were read on 06/09/2026 to confirm the basics list is the sport's
and not one programme's idea of it. **All three curricula teach the same movements in nearly
the same order** — the push, the swizzle, the glide, the stop, the two-foot turn, the slalom
— which is the argument for the basics existing as elements at all rather than as one
programme's syllabus.

- **Skate UK** (BIS) — a rink rendering of levels 1–8 at <https://ozonerink.co.uk/skate-uk/>.
  Secondary, and BIS has since rebranded to *Skate UK Fundamentals*, phases rather than
  levels, so rink pages listing *Skate UK Levels 1–10* are describing an older structure.
- **CanSkate** (Skate Canada) — skills descriptions and standards chart at
  <https://www.kwsc.org/data/uploads/pdfs/CanSkate_SkillsDesc_StandardsChart.pdf>. Stages
  Pre-CanSkate to 6, grouped Balance / Control / Agility rather than by level.

## Note on vocabulary

USFS says *moves in the field* where BIS says *skills* and Skate Canada says *skills
assessments*. They are not the same thing and should not be presented as equivalents —
the qualification guides name each body's own term and let the element pages do the
cross-referencing. See `docs/style.md`.
