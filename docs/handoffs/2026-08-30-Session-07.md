# The syllabus half — the machinery, and Skills 1

**Session 07 · 30/08/2026** — Cowork. Follows Session 06, which applied the boots and the
arms. The rig work is done for now; this is the other half of the project.

Skills 1 is written and checked. Skills 2–8 are the same job seven more times, and the
shape they will take is settled.

## What was decided before anything was written

Three calls, all Martyn's:

1. **One entry per exercise, not one per generation.** October 2026 is mostly additive, so
   an exercise carries a flag — `current`, `october2026`, `both` — rather than the guide
   holding two parallel sets of prose. 45 entries rather than 79, and nothing to drift.
2. **The exercise is the unit and it gets a page.** A skater says "Skills 3, exercise 4".
   The collection previously called `exercises` — off-ice physical capacities, defined,
   documented and always empty — is now `conditioning`, which is what it always meant.
3. **Skills 1 end-to-end first**, then the other seven. Machinery first, multiply after,
   which is how the derived tier was built.

## The checker, and the thing it caught

Four assertions:

1. Every reference resolves; a test's exercises are numbered 1..N with no gap or duplicate.
2. A test with exercises carries no element list of its own.
3. **The generation flag matches the document**, read out of `sources/bis/` with
   `pdftotext`. A flag cannot quietly disagree with the paper it came from.
4. **Every edge code the document names is reachable from the elements the exercise lists**
   — as an entry, or as an exit through `exitState`, so the check runs through the model
   rather than around it.

**Assertion 4 failed on its first run**, and was right to. Skills 1's slalom has a backward
side and I had listed only the four forward changes of edge:

    EDGE  skills-1-exercise-4  the document names LBI, RBO, LBO, RBI — not reachable
                               from any element listed (LFI LFO RFI RFO)

That is exactly the failure mode of transcription: nothing is wrong on the page, the prose
reads correctly, and four elements are simply absent. Nobody catches that by reading.

Fixed by listing the four backward edges rather than four backward changes of edge — the
backward side is two-foot only, and a one-foot change of edge would be claiming more than
the exercise asks.

Broken on purpose afterwards:

| broken | caught |
|---|---|
| an exercise naming a test that does not exist | REF, and ORDER as a knock-on |
| two exercises numbered 3 | ORDER |
| the October-only exercise flagged `both` | GEN, against the PDFs |
| one element dropped from a list | EDGE |
| the test keeping its own element list too | DUP |

**Assertions 3 and 4 skip with a notice on a clean clone**, because `sources/` is
gitignored and those documents are not ours to redistribute. A checker that fails for want
of a document nobody may publish would just get switched off.

## The October documents change more than the announcement says

Re-diffed mechanically, exercise by exercise, normalising hyphenation and case. The
manifest's earlier reading — *"almost nothing… no sequence was altered"* — does not hold.
**Four existing exercises were altered**, and BIS's update announcement mentions none:

| Level | Exercise | What changed |
|---|---|---|
| 1 | 4 — Slalom | The one-foot power changes become **optional**. A relaxation. |
| 2 | 3 — Forward 3-turns | Adds *minimum two lobes on each foot*. |
| 2 | 4 — Forward cross rolls | The same minimum added. |
| 3 | 5 — Forward spirals | Reworked: the toe-assisted step and the rotational direction both become optional, and an alternative entry appears without the hop. |
| 7 | 1 — FI choctaws & BO counters | *"This completes the exercise"* becomes *"then repeat the sequence"*. |

Everything else that differs is hyphenation or grammar, as the manifest said.

**Two consequences.**

- **The manifest's last gap is smaller than it looked.** The toe-assisted hop into the
  Skills 3 spirals was the only item left on its list. October makes it an optional variant
  of an optional variant, with a hop-free route to the same spiral. A Skills 3 page can be
  complete and honest without it, provided it says so.
- **An earlier manifest note had Skills 1's slalom backwards.** It said the current version
  "has no one-foot option" and used that to tell the generations apart. The current version
  *requires* the one-foot section; October is what adds the choice. Exercise count is the
  reliable test, and that is what the surrounding paragraph actually relies on.

`sources/bis/MANIFEST.md` is corrected on both counts, with the table above in it.

## Decisions locked

- **The exercise owns its elements; the test derives.** One list, in the place that owns it.
  Asserted, because two lists of the same thing is this repository's recurring failure.
- **A generation flag is a claim about a document**, so it is checked against the document.
- **Gaps are named, not omitted.** `notCovered` on the exercise. Skills 1's slalom asks for
  two-foot power changes of edge, which the rig cannot hold, and the page says so.
- **The paragraph is written from the skating, not from the document.** The useful question
  is "what would go wrong here", not "what does the sequence say". That is also the test for
  whether a sentence is ours or theirs — `docs/style.md`.

## Open questions

- **Is the prose right?** Five paragraphs of a non-expert's first draft, `verified: false`.
  This is the highest-value thing for a coach to read in the whole repository, because
  correcting an exercise paragraph corrects the page every skater at that level lands on.
- **Skills 8 is shaped differently** — sections rather than exercises, and Section 2 splits
  into 2A and 2B in October. Its headings do not match the `EXERCISE n` pattern the other
  seven use, so it needs looking at before it is transcribed.
- **How much does a level page say about what changes in October?** Right now: a chip on the
  exercise, and one sentence where it was altered. Once several levels are in it may want a
  page of its own.
- Everything still open from Session 06: a glyph for a boot seen from above its own opening;
  `onIce`; the free-boot angle; re-shooting.
