## Working notes

- **The VM cannot delete**, so a git command there that creates a lock leaves `.git/index.lock`
  or `.git/HEAD.lock` behind. Commit and push from the Mac (`osascript`), and remove stale
  locks there first: `rm -f .git/index.lock .git/HEAD.lock`.
- **Pushing needs the Mac**: the VM has no GitHub credentials.
- **`npm run check` from `osascript` must be backgrounded** or the call times out: run it with
  output to `_to_delete/check.log` and an `EXIT` line appended, then read the log from the VM
  after about three minutes. The `osascript` call reports an error when backgrounding; the
  check runs anyway.
- **The Mac has `omit=dev`**: `tools/a11y.mjs` wants
  `npm install --no-save --include=dev playwright axe-core` (both together, or one prunes the
  other).
- `node_modules` on the VM is the Mac's, so builds fail there (native binding). Build on the
  Mac.
- Social artwork is rendered in the cloud container with cairosvg, using the site's own fonts
  converted from `public/fonts` to TTF.
