## The custom domain, which cost an hour

**The Pages custom domain is set from `public/CNAME` in the uploaded artefact, not
from the settings page.** Editing it in the UI is undone by the next deploy, and while
the two disagree the site serves *nothing at either name* — apex and www both 404,
with a valid certificate on each, which reads exactly like a DNS fault and is not one.

The sequence was: settings said `www.figureskating.guide`, the artefact said the apex,
everything 404'd. Removing www from the settings and pushing again fixed it, because
the deploy re-asserted the apex from the file.

`www` now resolves (`CNAME martyn-gg.github.io.`) and serves, though it serves the
site directly rather than redirecting to the apex. Harmless: `Base.astro` emits
`<link rel="canonical">` from `Astro.site`, so every page served at www names the apex
as canonical.

## The front page

Martyn's framing, and it is the right one: *a home page is an advertisement for the
rest of the guide, and every subsequent page fulfils the promise*. The page argued
entirely in prose for a guide whose whole claim is that it draws the thing.

Now: the **eight edges drawn**, sorted forwards-before-backwards, outside-before-inside,
left-before-right, so mirror pairs sit side by side — four columns on a desktop, two on
a phone, never three, because three splits a pair across a row. Then **one three turn
that moves**, with pause, speed and mirror.

`src/components/EdgeThumb.astro` draws a tracing **at build time** — `buildTrace` is
pure geometry, so it runs in the frontmatter and ships an SVG path with no JavaScript
behind it. `EdgeDiagram` mounts a `requestAnimationFrame` loop per copy; eight of those
would be eight loops running before a reader has decided to stay. Motion budget on the
front page is one figure.

Nothing is addressed by slug. The grid asks for elements of kind `edge`; the animation
finds a turn whose `turn` is `three` and whose entry labels LFO. A renamed file breaks
the build rather than the page.

Two things only rendering caught. The copy said **"Press play"** on a diagram that
autoplays — it was telling the reader to press a button that already said pause. And
the site-wide footer's notation sentence now repeated the front page nearly word for
word, so it is suppressed on `/` and unchanged everywhere else, keyed off
`Astro.url.pathname` against `url()` rather than a literal `'/'`.

## `check:prose` — the seventeenth checker

Session 12 asked for it. It reads `dist/` and asserts three things about the text a
reader actually sees:

1. no two words joined across an **inline** boundary
2. no comma or semicolon without a space after it
3. no sentence running straight into the next

**It found seven real faults on the first run** — "are on*older test names*", "it may
be on*other names*", "try*older test names*", "National Skills Tests*handbook*",
"Check it against*BIS's own test information*before you rely on it", "British Ice
Skating's*new ice dance test structure*announcement". All fixed.

Getting there took three tunings, and the tunings are the interesting part:

| attempt | findings | true |
| --- | --- | --- |
| every tag boundary | 2,772 | 7 |
| ignore close-into-open | 22 | 7 |
| plus read the stylesheet | 7 | 7 |

**A close followed by an open is two sibling elements meeting** — a chip after a link,
a sub-label after a heading — and CSS almost always sets one of them apart. A run
*without* that transition is text meeting markup, which is prose, which is where the
fault is.

**And a class the stylesheet makes `display:block` is not inline, whatever the tag
says.** `<th>Three turn<span class="sub">rotates into</span></th>` reads as two lines.
So the checker reads `dist/_astro/*.css`, collects every class named in a rule that
sets a separating display, and treats those as blocks — over-inclusive on purpose,
because silence is the cheaper failure for a checker nobody would keep if it cried
wolf.

Known blind spot, documented in the file: the rule is lower-case into lower-case, so
`the<b>Left` goes unseen where `the<b>left` is caught. That is the right way round — a
capital mid-sentence is something the eye catches unaided.

## Verifying without the Mac

The Linux VM this session reaches cannot build the repo: `node_modules` carries the
darwin-arm64 rolldown binding, and running `npm install` there would clobber a working
tree. The route that works is to clone the public repo into the cloud container,
`npm ci`, copy the changed files across and run `npm run check` there. Playwright
screenshots work in the container with `executablePath: '/opt/pw-browsers/chromium'`.
