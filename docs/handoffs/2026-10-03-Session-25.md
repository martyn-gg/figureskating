## Things to know

- Run git and the build on the Mac shell only. The device VM's node cannot build (arm64
  binding) and has left `index.lock` behind twice.
- Pages that have country copies live under `src/pages/[...cc]/`. A link written with the
  page's local `url()` stays in the country; `check:countries` fails any that do not.
- `tools/search.mjs` skips the country directories on purpose; `check:countries` covers them.
