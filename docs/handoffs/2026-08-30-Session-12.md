£35.48 ex VAT, about £42.58 inc VAT per year. Hosting is free.

`astro.config.mjs` is now `site: 'https://figureskating.guide'`, `base: '/'`.

**The base path used to exist in three places.** `tools/links.mjs` and
`tools/_rig.mjs` each carried the literal `'/figureskating'`, which was correct
for exactly as long as the site lived under a project path on github.io. Both now
read it from the config through `BASE` / `stripBase` in `_rig.mjs`. Had they been
left alone they would still have passed — the replace becomes a no-op at `'/'` —
which is precisely the kind of decoration the house rules are against.

`public/CNAME` carries the apex. GitHub then redirects www to it automatically,
provided both records exist.

### DNS, for whoever sets it up next

An apex cannot be a CNAME (RFC 1034: it cannot coexist with the SOA and NS
records that have to live there). Four A records and four AAAA records:

    A     @   185.199.108.153 / .109.153 / .110.153 / .111.153
    AAAA  @   2606:50c0:8000::153 / :8001::153 / :8002::153 / :8003::153
    CNAME www martyn-gg.github.io.

A CNAME target is a **hostname**. `martyn-gg.github.io/figureskating` is not a
valid one — DNS has no paths.

### The coach route

An application is an email, not a form post. No sign-up, no account, no session,
no applicant record on a server. `/coaches/` builds a pre-filled mailto with the
eight fields we need.

Eligibility is deliberately wide, and this was Martyn's correction, not mine: a
licence is permission to coach, a qualification is evidence of knowledge, and the
two are not the same. Current licence, *or* a lapsed one, *or* a qualification
still held, *or* a judging/technical appointment (serving or retired), *or* a
vouch from someone already verified.

The scheme as written on the page: sign-off attaches to a **passage**, not a page
(307 pages share 159 passages — 477 approvals rather than 921); three approvals
give a tick; **one objection takes it straight back off**; each tick records who
and in what capacity. Comments are verified people only; everyone else gets the
corrections address.

## Icons and manifest

`tools/icons.mjs` generates `icon.svg`, `icon-192`, `icon-512`,
`icon-maskable-512` (12.5% safe margin) and `apple-touch-icon` from
`src/lib/tokens.js`. Needs `sharp`, which is not a dependency — it asks politely,
like `browser()` does for Playwright. Run it after changing a colour; commit the
output.

The mark is a serpentine — two lobes, opposite edges, the change of edge marked
in `edge-out` teal. The first attempt was a freehand cubic S and looked like a
kinked "2" at 192 px; two arcs of equal radius, point-symmetric about the centre,
read properly. **Rendered and looked at rather than reasoned about**, which is the
only reason the first one got thrown away.

`public/manifest.webmanifest` is gone; `src/pages/manifest.webmanifest.js`
replaces it. A file in `public/` cannot see the base path, so `start_url` was `"."`
and worked by accident, and it named no icons at all.

## What the checkers caught

**`check:search` failed on the two new pages**, exactly as designed: assertion 1
counts against `dist/`, so a page that builds and is unsearchable fails. About and
coaches joined `NOT_RECORDS` — they are pages about the site, not about skating,
and an index of movements should not have "spiral" competing with a paragraph on
domain costs.

**JSX ate five spaces.** A text node whose whitespace contains a newline is
trimmed where it meets an expression or an element, so

    {counts.twizzle} twizzles,
    {counts.transition} transitions

rendered as `32 twizzles,36 transitions`, and `start with the` + a link on the
next line rendered as `theleft forward outside edge`. Five instances across the
four new pages, all fixed with an explicit `{' '}`. **None of the sixteen checkers
sees this** — it is not a broken link, a bad colour or a wrong angle, it is prose.
It was caught by rendering the pages, stripping the tags and reading the text.
That is a candidate for a seventeenth checker: two words joined across a tag or
expression boundary in the visible text of a built page.

## Deployment

`.github/workflows/pages.yml`: checkout, Node 26, `npm ci`, `npm run check`,
upload `dist/`, deploy. The full chain gates the deploy — `npm run check` runs its
own `astro build`, so the uploaded artefact is the checked one. The four
Playwright checks are deliberately not in CI: slow, they need a browser download
every run, and they are the ones a human should be looking at.

`package-lock.json` is no longer gitignored, because `npm ci` needs it.
`shots/` now is — 3.3 MB of review screenshots that go stale the moment a pose
moves.
