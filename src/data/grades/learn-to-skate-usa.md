Learn to Skate USA's Basic Skills are six levels, Basic 1 to Basic 6, with Snowplow Sam
below them for the youngest skaters. They take a beginner from the first two-foot glide to
crossovers both ways, the first three turns, a spiral and a one-foot spin.

The lists below are the elements event from Learn to Skate USA's competition manual, dated
August 2026: what a skater performs at each level, in order. It is the one level-by-level list
on Learn to Skate USA's own site. The full Basic Skills curriculum is no longer published there,
so a class may cover more than appears here. Counts and directions are the manual's.
