Three rocker-choctaws in a row on each side, which is the first time a cluster has to be
repeated rather than shown. Repetition is the assessment here: one of these can be produced
by a skater who is concentrating, and three in succession cannot.

The cluster itself is two changes of lobe in immediate succession, done in different ways. A
rocker moves the lobe on one foot with the edge held, and the closed choctaw that follows
moves it again by another route entirely. So the body is asked to accept
a new lobe, settle, and then reverse — and the second half of that has to be set up during
the first, because there is no edge in between to do it on.

What makes the serpentine work is the change of edge at the end of each side. It is the only
part of the exercise that is not a turn, and it decides whether there is anything left for
the next side.
